# Верификация ФИО врачей (R05)

Расшифровки BitrixGPT регулярно искажают фамилии врачей. При анализе сверять
упомянутые в расшифровке имена со справочником сотрудников (user.get).

## Известные искажения

| Как в расшифровке | Реальное ФИО |
|---|---|
| Китингов | Этингоф Анна Михайловна |
| Шортникова | Шурникова Наталья Сергеевна |
| Серебристый / Серебристый | Серебрийский И.И. |
| Абломасов | Аболмасов А.Е. |
| Бриский / Брицкий | Бриский Илья Исакович |
| Васильев В.И. | Васильев Владимир Иванович (ревматолог) |

## Популярные врачи (высокий спрос)

- **Васильев Владимир Иванович** (ревматолог) — постоянный дефицит записи
- **Шурникова Наталья Сергеевна** — активный спрос
- **Бриский Илья Исакович** — жалобы на недоступность (не отвечает на анализы)
- **Серебрийский И.И.** — упоминается в WhatsApp-подтверждениях

## Алгоритм верификации (СТРОГИЙ ПОРЯДОК)

1. Извлечь все упомянутые фамилии/имена из расшифровки/сообщений
2. **СНАЧАЛА** → точный поиск по справочнику `user_map` (user.get)
   - Если нашлось точное совпадение (или с инициалами) → **это реальный врач, не искажение**
   - Пример: "Шорникова Л.А." → найдено "Шорникова Людмила Александровна" → ✅ реальный врач
3. **ТОЛЬКО ЕСЛИ** в user_map не нашлось → проверить таблицу известных искажений выше
4. Если нашлось в таблице искажений → использовать правильное ФИО в отчёте
5. Если не нашлось нигде → отметить в отчёте как неизвестный врач

> ⚠️ Нельзя применять таблицу искажений если фамилия уже найдена в user_map — два врача могут иметь похожие фамилии (например, Шорникова Л.А. ≠ Шурникова Н.С.)

# Формат отчёта в chat31598

Отчёт читают администраторы — **не технические специалисты**.
Дата в шапке = **день отчёта** (`triage.json` → `report_date` = вчера МСК).

## Запрещённые слова в чате

`UF-gap`, `UF`, `REST`, `API`, `scope`, `batch`/«батч», `manifest`, `enum`, `webhook`,
`transcript`, `activity`, `timeline`, `JSON`, `dry-run`, коды `R01…R07`, `F01…F03`,
флаги `C` / `E`, имена полей `UF_CRM_…`, «группа A/B/C».

## Перевод терминов

| Внутренний | В чат |
|---|---|
| UF-gap | «разговор не расшифровался» |
| Группы A/B/C | «закрыли вчера» / «связь на вчера» / «активность без следующего шага» |
| Флаг C (R02) | «связывались всего N раз — мало» |
| Флаг E (R06) | «стоит "Запись", но в 1С записи нет» |
| R08 | «номер агрегатора (ПроДокторов) — перезвон невозможен» |
| F03 | «стоит "Отказ", хотя не отказывался» |

## Самопроверка (только лог прогона, не в chat31598)

```
[ ] Дата = report_date (вчера МСК)
[ ] Числа = triage.json counts
[ ] Нет запрещённых терминов
[ ] Блок «Что заполнил робот»
[ ] gap_only — только номера, без карточек
[ ] У 🔴/⚠️ четыре строки + ссылка BB-код
[ ] Кнопки бота только под «Что сделать сегодня»
```

## Шаблон отчёта

Дату словами: «9 сентября».

```
📊 Проверка обращений за [9 сентября]
Посмотрели [N] карточку: [A] закрыли вчера, [B] с назначенной на вчера связью,
[C] с вчерашней активностью без следующего шага.

🔴 Похоже, потеряли пациента: [N]
⚠️ Нужно доделать: [N]
✅ Всё в порядке: [N]
ℹ️ Просто консультация, запись не планировалась: [N]
🎧 Разговор не расшифровался: [G] — по ним смотрели только переписку и карточку

🤖 Что заполнил робот
• Обновлений в карточках: [N]
• Тема обращения: было [x] из [T], стало [y] — добавил [w]
• Кто рекомендовал: было [x] из [T], стало [y] — добавил [w]

━━━━━━━━━━━━━━━━━━━━━━━
ЧТО СДЕЛАТЬ СЕГОДНЯ

🔴 [URL=https://laskov-partners.bitrix24.ru/crm/lead/details/{ID}/]#{ID}[/URL] — [Администратор]
Что хотел пациент: …
Что произошло: …
Почему это важно: …
Что сделать: …

━━━━━━━━━━━━━━━━━━━━━━━
🎧 Разговор не расшифровался: [G] из [L] ([pct]%)
Номера: #…, #…
Что это значит: звонок состоялся, запись не сохранилась. Действий не требуется.
(если G=0 — секцию не писать)
```

Если делать нечего — шапка, «Что заполнил робот», при необходимости блок про расшифровки,
строка: «Обращений, требующих действий, нет».

## Кнопки бота 23032

Только под карточки «Что сделать сегодня». Scope `imbot` обязателен.

```python
POST(WEBHOOK + "imbot.message.add.json", {
  "BOT_ID": 23032, "CLIENT_ID": "ai_review_bot", "DIALOG_ID": "chat31598",
  "MESSAGE": "⚠️ #<lead_id> — <администратор>. <суть>",
  "KEYBOARD": [{"TEXT":"❌ Не согласен","COMMAND":"disagree","COMMAND_PARAMS":"<lead_id>",
                "BG_COLOR":"#E55D53","TEXT_COLOR":"#FFFFFF","DISPLAY":"LINE"}]
})
```

Кодировать через Python + `json.dumps` + UTF-8. PowerShell не использовать.
